## 孩子怎么用（页面上也写了）

1. 先读顶部「速度小课堂」知识点；
2. 自己做题（可以写在每题的“小练习本”里，会自动保存在本机浏览器）；
3. 想不出 → 点「💡 小提示」；还不行 → 再点一次「再给一点点提示」；
4. 最后才看「📖 看完整解法」（分步骤 + 小线段图 + 答案 + 验算）；
5. 做完点「我做出来啦！」→ 点亮小星星，全部完成会出现通关横幅。

## 页面功能

- 解法默认隐藏，可分级展开（提示 → 第二层提示 → 完整解法），避免直接剧透答案；
- 解答全部按**小学生思维**撰写：先找不变量、画图、分步算式、验算，不列方程；
- 题目按星级分组：一星热身 / 二星闯关（举一反三）/ 三星挑战（举一反三）；
- 做题进度、已得星星数、名字、草稿都保存在浏览器本地，下次打开可继续；
- 「清空进度与草稿，重新做一遍」可重置。

## 以后出「练习二」怎么做

1. 复制本文件，改名，如 `练习二-XXXX.html`；
2. 修改顶部 `<title>` 与题目前面小节；
3. 找到脚本里的 `var QS = [...]` 数组，按同样的字段把新题目写进去（字段含义见数组上方注释）：
   - `id` 题号；`lv` 星级（1/2/3）；`text` 题干；`hint` 第一层提示；`hint2` 第二层提示（可选）；
   - `steps` 分步解法 `[{t:小标题, d:讲解}]`；`fig` 配图 HTML（可选）；`ans` 答案句；`check` 验算；`note` 小提醒。
4. 小星星总数为各题星级之和，页面会自动统计，无需改动其他代码。
