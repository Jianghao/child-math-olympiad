矛盾推理小课堂

做题之前，先分清是“合走”还是“补差距”

假设假设法：先猜再查

看到“每人只说对一半”“只有一个人说真话”，就请出法宝——假设法：

  • ① 先挑一句话，假设它是对的
  • ② 顺着往下推，看看会得到什么
  • ③ 出现矛盾点（两个人抢同一个名次、同一个数又对又错）→ 假设错了，换另一句再试

口诀：假设 → 推理 → 找矛盾 → 换假设。

示范看一道例题（四人名次）

甲猜：豆豆1、小浩2；乙猜：壮壮1、军军4；丙猜：豆豆2、军军3。每人只对一半。

  • 假设“豆豆第1名”对 → 小浩不是2 → 壮壮也不能1 → 乙只能对“军军4” → 丙只能对“军军3”→ 军军又4又3，矛盾！
  • 所以换过来：“小浩第2名”对 → 壮壮1、军军3、豆豆4

答案：壮壮1、小浩2、军军3、豆豆4。这就是课本“研学探究”里那道例题。

侦探三种常考类型

  • 猜数字 / 密码：每句话都“对一半”→ 先假设某一位对了，别的全试。
  • 真假话（“至少几个人错”）→ 从 0 个、1 个、2 个……挨个假设“说错的人数”，让每句话自己和自己合得上。
  • 名次 / 谁快谁慢：画个小表格，打 ✓ / ✗，两个人抢同一名次就是矛盾点。
